# Realtor Playbook — Obsidian vault

A side product: an information package for real estate agents built from the RealtyBoost research.

## Open it in Obsidian (2 minutes)

1. Install Obsidian (free): https://obsidian.md
2. Download this `vault` folder to your computer (from GitHub: **Code → Download ZIP**, then unzip; the vault is the `vault` folder inside).
3. In Obsidian: **Open folder as vault** → choose the `vault` folder.
4. Open **Home** to start.
