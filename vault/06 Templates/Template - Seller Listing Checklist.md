# Template - Seller Listing Checklist

**In short:** A checklist from first meeting to going live. Adjust to your state and brokerage. Guide: [[Listing Appointment Guide]].

## Before the appointment
- [ ] Property research done (records, prior sales, permits)
- [ ] CMA prepared ([[CMA Basics]]) with disclaimer approved by broker
- [ ] Net sheet prepared at 2-3 prices ([[Commission & Net Sheet Basics]])
- [ ] Marketing plan prepared
- [ ] All owners confirmed to attend

## At the appointment
- [ ] Reasons and timeline for selling discussed
- [ ] Walkthrough completed; notes on condition and upgrades
- [ ] Pricing range discussed using comps
- [ ] Compensation and listing terms explained (negotiable)
- [ ] Questions answered

## Paperwork (use your broker's forms)
- [ ] Listing agreement signed by all owners
- [ ] Agency/relationship disclosure
- [ ] State seller property disclosure
- [ ] Lead-based paint disclosure (homes built before 1978)
- [ ] HOA documents requested
- [ ] Mortgage payoff request / lender info
- [ ] Wire fraud warning delivered
- [ ] Other state/local required disclosures: 

## Preparing the home
- [ ] Repairs list agreed
- [ ] Decluttering / cleaning / staging
- [ ] Curb appeal
- [ ] Pre-listing inspection (optional)
- [ ] Keys / lockbox / showing instructions
- [ ] Pets and showing arrangements

## Marketing
- [ ] Professional photos / video scheduled
- [ ] Listing description reviewed for accuracy and fair housing ([[Listing Description Guide]], [[Fair Housing Advertising]])
- [ ] Sign installed (if permitted)
- [ ] MLS entry checked
- [ ] Open house plan ([[Open House Playbook]])
- [ ] Social posts ([[Social Media Playbook]])

## After going live
- [ ] Showing feedback shared with seller
- [ ] Weekly update to seller
- [ ] Offer review plan agreed
- [ ] Price review date set:
