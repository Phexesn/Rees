# Platform Briefs: Summary

As of 2026-11-03. Official platform pages were not reachable from the research environment, so all values are from secondary sources. Items marked "unverified" must be checked before they go into a prompt template. See each file for sources.

| Platform | Max length | Ideal length | Key rule |
|---|---|---|---|
| MLS public remarks | Varies by board: unverified (1,000 used as conservative default) | Full property description, within limit | No contact info, links, open-house or showing details (CRMLS, Northstar); Fair Housing applies. See `mls-listing-rules.md`. |
| MLS private remarks | Varies by board: unverified (500 used as default) | Agent notes only | Restricted from public view (RESO). Never copy into public fields. |
| Instagram caption | 2,200 characters [S] | First line under ~125 chars; body 100–150 words | **5 hashtags max** per post/Reel (from Dec 2025) [S]. Links not clickable. |
| TikTok caption | 2,200 characters on API; 4,000 in-app reported [conflicting] | 1–2 sentences | Hook in first 1–3 s; 3–5 hashtags. |
| YouTube Shorts | **3 minutes** [S] (since Oct 2024) | 30–45 s | 9:16 vertical; title keyword-first. |
| Facebook post | No hard limit found [U] | 40–100 words listings; up to ~250 story | Listings via personal profile, not Page (since Dec 2022) [S]; brokerage name in ad. |
| LinkedIn post | 3,000 characters [S] | 1,000–1,500 thought leadership; 150–300 updates | 3–5 hashtags; no fixed-return investment claims. |
| X (Twitter) post | 280 free; 25,000 Premium [S] | 180–240 free | CJK text counts double (140 free) [S]. |
| Zillow / Realtor.com | Taken from MLS feed; display ~140 / ~120 chars before "see more" [U] | First 120 chars carry the message | One MLS-compliant remarks string, reused everywhere. |
| Marketing email (bulk) | No length rule; CAN-SPAM needs physical address | 1 CTA, short | SPF, DKIM, DMARC; one-click unsubscribe; spam rate under 0.3% [S]; opt-outs in 10 business days [S]. |
| SMS (US, A2P) | 160 GSM chars / 70 UCS-2 per segment [U] | Under 160 chars | Prior express written consent; send 8 a.m.–9 p.m. local [U/S]; honor STOP; A2P 10DLC registration required. |

## Legend
- **[S]** = secondary source (search snippet or vendor page) with a URL in the file.
- **[U]** = unverified, commonly cited.
- Official sources not reached: devdocs.crmls.org, northstarmls.com, ddwiki.reso.org, kb.crmls.org, help.instagram.com, support.google.com. Re-verify these before launch. Allow those domains in the session network settings to re-run.
