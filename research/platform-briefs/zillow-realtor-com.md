# Zillow and Realtor.com: Listing Description SEO

As of 2026-11-03. Portal help pages were not reached. Most portal descriptions come from the MLS feed, so MLS limits usually bind first.

Tags: **[S]** = secondary source. **[U]** = unverified, commonly cited.

## How descriptions flow
1. Agent enters remarks in the MLS (public remarks field).
2. MLS sends listing data by feed (IDX, or direct feeds where the MLS and portal have an agreement).
3. The portal displays the description, possibly truncated or with the MLS's own limits applied.

Implication: **write one MLS-compliant public remarks field and use it everywhere**. Do not generate a different, longer description for the portal unless the portal provides its own input field and the MLS allows it.

Older Inman reporting says some MLSs limit what they send to portals, so a portal may show less than the MLS holds [S] (inman.com, 2014 coverage; dated).

## Display limits (what readers see first)
| Portal | Visible before "see more" | Status |
|---|---|---|
| Zillow | ~140 characters | [U] vendor blog |
| Realtor.com | ~120 characters | [U] vendor blog |

Put the strongest sentence in the first 120 characters.

## SEO and keyword rules
- Include, naturally: property type, beds/baths, city and neighborhood name, one or two features (garage, updated kitchen, yard).
- Keep keyword stuffing out. Portals and Fair Housing reviewers both penalize it.
- Use the neighborhood name the buyers search for, not only the official subdivision name, when the MLS permits it [U].

## Prompt-writer rules
1. Output the public remarks string once, within the MLS limit, and reuse it.
2. Front-load the first 120 characters: price-relevant feature plus location.
3. No phone numbers, URLs, or "call me" language (see mls-listing-rules.md).
4. Check Fair Housing wording on the same string.
